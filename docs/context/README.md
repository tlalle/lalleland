# Context documents

Drop the knowledge-consolidation documents here (`.docx`, `.md`, `.txt`, or images
of diagrams). Files in this folder are treated as **source material, not
specification** — they are read and reconciled into `docs/PROJECT_BRIEF.md`, and
the originals are never edited.

When adding a document, it helps to note in the filename or the commit message:

- roughly when it was written, so later documents can supersede earlier ones
- whether it records decisions that were **confirmed**, or options that were
  merely **proposed** by a chat agent

Diagrams embedded in Word files do not survive text extraction. Export those as
PNG and commit them alongside the document.
